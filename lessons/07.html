Где работает модель: облако, сервер, API

Где физически лежит модель, какой путь проходит ваш вопрос, что такое API и ключ, за что вы платите и кто видит ваш текст.

Где лежит модель

Вопрос на разминку

Вы пишете Claude в приложении на телефоне. Где в эту секунду находится модель? Не в телефоне. Она за сотни километров, а ответ проделывает этот путь по кусочку — потому он и «печатается» на экране.

Модуль 1 разобрал, что у модели внутри. Этот — где она стоит, сколько ей нужно памяти и во что обходится ответ. Начнём с адреса. Модель — это веса (урок 3), то есть файл с числами. У больших моделей он огромный: у самых крупных — триллионы параметров, это терабайты. В телефон такое не поместится. Поэтому модель лежит на серверах.

Сервер — компьютер без экрана и клавиатуры, который работает круглосуточно и отвечает на запросы по сети. Тысячи серверов стоят в дата-центрах. Внутри сервера — ускорители: видеокарты и специализированные чипы для быстрого умножения больших таблиц чисел (урок 3). На них модель и считает ответ.

«Облако» — это чужие серверы, которыми вы пользуетесь через интернет. Их хозяина — компанию, которая держит модель у себя и отвечает на запросы, — называют провайдером: Anthropic, OpenAI, Google.

Знакомьтесь: ftm

Сервер бывает и свой. ftm — домашний компьютер Сергея, одного из учащихся: старый процессор i3-6100T, 16 ГБ памяти, без видеокарты. Он включён круглосуточно — значит, это тоже сервер, только маленький и свой. На нём живут бот «Жемчужины», который записывает голосовые заметки, распознавание рукописных дневников и этот курс. Дальше ftm — наш пример домашнего железа: небольшую модель можно скачать и запустить прямо на нём (нижняя строка схемы).

Путь вашего вопроса

  1. Вы набираете вопрос в приложении или на сайте.
  2. Приложение отправляет текст через интернет зашифрованным: по дороге его не прочтут1.
  3. Сервер провайдера кладёт текст в окно модели (урок 5).
  4. Модель на ускорителях пишет ответ токен за токеном (урок 1).
  5. Токены сразу летят обратно, по одному.

Приложение — только окно; сайт и приложение одного провайдера ведут к одной и той же модели.

API — окошко для программ

К модели ходят не только люди через чат. Программа тоже может отправить текст на адрес провайдера и получить ответ. Правила такого разговора — в каком виде слать вопрос, в каком ждать ответ — называются API (от англ. application programming interface, «интерфейс для программ»).

Чтобы провайдер знал, кому выставить счёт, программа предъявляет ключ API — длинный секретный пароль вида sk-ant-…. Кто знает ключ, тот тратит ваши деньги, поэтому его берегут как пароль от банка (урок 27). Через API модель вызывают программы: боты, сайты, чужие приложения.

Можно ли без программирования?

Да. Ключ выдают в личном кабинете разработчика на сайте провайдера, а вставляют в готовые программы «со своим ключом». В курсе это не понадобится: агент для кода работает и по подписке (урок 14).

Как платят

  • Подписка — фиксированная плата в месяц за чат и приложения. Взамен — лимиты: сколько можно работать за 5 часов и за неделю2. В токенах их не объявляют: расход зависит от модели и длины разговора. Сколько осталось, показывает шкала: в Claude — Настройки → Использование.
  • Оплата за токены по API — счёт по факту. Отдельно считаются входные токены (что модель прочитала: вопрос, файлы, вся история разговора) и выходные (что написала). Выходные дороже в 5 раз3. Почему — ответ в уроке 9.

Пакетный режим: пачка запросов без спешки — за полцены (подробно — урок 10).

Что видит провайдер

Облачная модель видит всё, что лежит в окне: вопрос, файлы, историю. Что с этим текстом происходит дальше, решают условия сервиса4.

  • Чат на личном тарифе. Переписка может идти на обучение будущих моделей, если включена настройка. У ChatGPT она включена по умолчанию, у Claude называется «Помогать улучшать Claude» — проверьте у себя.
  • API и рабочие тарифы (для компаний). На обучение по умолчанию не идут; запросы хранятся ограниченный срок (у Anthropic — 30 дней). «Не хранить вовсе» — отдельный договор для организаций.

Читают ли ваш текст люди? На серверах он хранится зашифрованным. У Anthropic сотрудники по умолчанию открыть переписку не могут. Исключений два: вы сами отправили отзыв о разговоре — или автоматическая проверка пометила его как нарушение правил; тогда его смотрит узкая группа проверяющих. У других провайдеров правила свои — читайте условия своего сервиса.

Неопубликованные данные

Результаты лаборатории до публикации — не для личного чата. Варианты: договор организации с провайдером или модель на своём компьютере (урок 10).

Подписка или оплата за токены

Сколько стоил бы ваш чат, если платить по API (токенов на вопрос × вопросов в месяц)? Помните урок 5: модель учитывает всё окно. По API вся история с каждым сообщением снова оплачивается как входные токены (со скидкой, если начало не менялось). Поэтому входных токенов много больше, чем вы набрали.

Цены Claude по API — настоящие, на ноябрь 2026. Размеры разговоров условные, без кэша и пакетной скидки: это порядок величин, а не счёт. Лимиты подписки в токенах Anthropic не публикует, поэтому сравниваем только с ценой подписки.

Биотехнология

Открытые статьи о ферментах можно отдавать любому облаку: они и так публичные. Неопубликованные кинетические данные своей лаборатории — другое дело. Три честных варианта: обезличить и отправить в чат; работать через API или тариф для организаций, где данные не идут на обучение; разбирать локально (урок 10).

Свои проекты

Бот «Жемчужины» на ftm разбирает заметки облачной моделью Claude Haiku — через API, со своим ключом. Ключ лежит отдельно от программы, в закрытом файле настроек на самом ftm: программу можно показать кому угодно, а ключ — никому. Расход виден в личном кабинете провайдера, там же стоит месячный лимит.

Сноски
  1. Как устроен путь «компьютер → интернет → сервер» без единой формулы: кабели, адреса, маршрутизаторы — с картинками, на русском. Хорошо ложится на схему урока. MDN: Как работает Интернет (статья, рус., 10 мин).
  2. Тарифы Claude на ноябрь 2026: Free — бесплатно с малым лимитом; Pro — $20 в месяц ($17 при оплате за год); Max — $100 (в 5 раз больше Pro) и выше. Лимита два: на сессию (обновляется каждые 5 часов) и недельный. Расход зависит от длины разговора, файлов, выбранной модели и режима рассуждения; чат, приложение для компьютера и агент для кода берут из одного запаса. Claude: Plans & pricing и How do usage and length limits work? (проверено 11.11.2026).
  3. Официальная страница цен, проверено 11.11.2026. Там же скидки. Чтение из кэша у Sonnet и Opus 5.5 — 5 % обычной цены входа, у Haiku 5.5 — 10 %; зато первая запись в кэш на четверть дороже обычного входа (в кэш на час — вдвое), так что кэш окупается со второго обращения. Пакетный режим — минус 50 % на вход и выход. У Haiku 5.5 запрос длиннее 100 тысяч токенов стоит в 5 раз дороже. Claude Docs: Pricing.

Короткие справки, которые стоит прочитать про сервис, которым пользуетесь именно вы (по 5 минут, англ.): где переключатель обучения в Claude — How do I change my model improvement privacy settings?; сколько хранится переписка (до 5 лет в обезличенном виде при включённом обучении, удалённые чаты стираются за 30 дней, помеченные как нарушение — до 2 лет) — How long do you store my data?; шифрование и доступ сотрудников — How does Anthropic protect the personal data of Claude users?; что происходит с запросами по API — API and data retention.

Главное
  • Облачная модель лежит на серверах провайдера; приложение и сайт — только окно к ней.
  • API — окошко модели для программ; ключ API — их пароль и ваш кошелёк.
  • Подписка — фиксированная плата и лимиты; API — оплата за входные и выходные токены, выходные дороже в 5 раз.
  • Облако видит ваш текст: что с ним дальше, решают условия тарифа. Полная приватность — только модель на своём компьютере.
Задание на 10 минут

Откройте настройки чата, которым пользуетесь. Найдите и запишите три вещи: ваш тариф; где смотреть, сколько лимита осталось (в Claude: Настройки → Использование); включено ли использование переписки для обучения (в Claude: Настройки → Конфиденциальность → «Помогать улучшать Claude»; в ChatGPT: Настройки → Управление данными → «Улучшить модель для всех»). Решите, оставить ли настройку как есть.

Сквозной проект · шаг 7

Время: ≈ 10 минут. Запишите в журнал проекта запись типа решение из двух пунктов:

  1. Тариф. Каким продуктом и на каком тарифе вы работаете сейчас; включено ли обучение на вашей переписке (из задания выше).
  2. Данные. Что из проекта можно отдавать провайдеру. Открытые статьи о ПЭТ-гидролазах — можно: они и так публичные. Свои неопубликованные измерения — нельзя либо только после обезличивания; запишите, как решили вы.

Где будет работать модель на каждом этапе — в облаке или на своём компьютере, — пока не решаем: это шаг 10, когда посчитаем память, скорость и деньги.
