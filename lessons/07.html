Где работает модель: облако, сервер, API

После урока вы сможете сказать, где физически лежит модель, каким путём идёт ваш вопрос, что такое API и ключ, за что вы платите и кто видит ваш текст.

Где лежит модель

Вы пишете Claude в приложении на телефоне. Где в эту секунду находится модель — и почему ответ «печатается» на экране по кусочку?

Разгадка. Не в телефоне. Модель за сотни километров, а ответ проделывает этот путь по кусочку, токен за токеном, — потому он и «печатается». Как устроен этот путь — в следующих двух разделах.

Модуль 1 разобрал, что у модели внутри. Этот — где она стоит, сколько ей нужно памяти и во что обходится ответ. Начнём с адреса. Модель — это веса (урок 3), то есть файл с числами. У больших моделей он огромный: у самых крупных — триллионы параметров, это терабайты. В телефон такое не поместится. Поэтому модель лежит на серверах.

Сервер — компьютер без экрана и клавиатуры, который работает круглосуточно и отвечает на запросы по сети. Тысячи серверов стоят в дата-центрах. Внутри сервера — ускорители: видеокарты и специализированные чипы для быстрого умножения больших таблиц чисел (урок 3). На них модель и считает ответ.

«Облако» — это чужие серверы, которыми вы пользуетесь через интернет. Их хозяина — компанию, которая держит модель у себя и отвечает на запросы, — называют провайдером: Anthropic, OpenAI, Google.

Знакомьтесь: ftm

Сервер бывает и свой. ftm — домашний компьютер Сергея, одного из учащихся: старый процессор i3-6100T, 16 ГБ памяти, без видеокарты. Он включён круглосуточно — значит, это тоже сервер, только маленький и свой. На нём живут бот «Жемчужины», который записывает голосовые заметки, распознавание рукописных дневников и этот курс. Дальше ftm — наш пример домашнего железа: небольшую модель можно скачать и запустить прямо на нём.

Путь вашего вопроса

  1. Вы набираете вопрос в приложении или на сайте.
  2. Приложение отправляет текст через интернет зашифрованным: по дороге его не прочтут1.
  3. Сервер провайдера кладёт текст в окно модели (урок 5).
  4. Модель на ускорителях пишет ответ токен за токеном (урок 1).
  5. Токены сразу летят обратно, по одному.

Приложение — только окно; сайт и приложение одного провайдера ведут к одной и той же модели.

API — окошко для программ

К модели ходят не только люди через чат. Программа тоже может отправить текст на адрес провайдера и получить ответ. Правила такого разговора — в каком виде слать вопрос, в каком ждать ответ — называются API (от англ. application programming interface, «интерфейс для программ»).

Чтобы провайдер знал, кому выставить счёт, программа предъявляет ключ API — длинный секретный пароль вида sk-ant-…. Кто знает ключ, тот тратит ваши деньги, поэтому его берегут как пароль от банка (урок 27). Через API модель вызывают программы: боты, сайты, чужие приложения.

Справка: можно ли пользоваться API без программирования

Да. Ключ выдают в личном кабинете разработчика на сайте провайдера, а вставляют в готовые программы «со своим ключом». В курсе это не понадобится: программа-агент, с которой мы начнём работать в уроке 14, работает и по подписке.

Как платят

  • Подписка — фиксированная плата в месяц за чат и приложения. Взамен — лимиты: сколько можно работать за 5 часов и за неделю2. В токенах их не объявляют: расход зависит от модели и длины разговора. Сколько осталось, показывает шкала: в Claude — Настройки → Использование.
  • Оплата за токены по API — счёт по факту. Отдельно считаются входные токены (что модель прочитала: вопрос, файлы, вся история разговора) и выходные (что написала). Выходные дороже в 5 раз3. Почему — ответ в уроке 9.

Справка: две скидки по API, которые пригодятся в проекте, — кэш подсказки и пакетный режим · 1 мин

Кэш подсказки: повторённое без изменений начало запроса (та же инструкция, та же статья) провайдер читает со скидкой в 10–20 раз; хранит он его 5 минут после последнего обращения, по желанию — час.

Пакетный режим: пачка запросов без спешки — за полцены (подробно — урок 10).

Вы задаёте 30 вопросов в день по длинной статье. Что выйдет дороже за месяц на старшей модели Opus: подписка за $20 или оплата тех же разговоров за токены?

Оплата за токены: около $135 против $20. По API вся история разговора — вместе со статьёй — с каждым сообщением оплачивается заново как входные токены. Проверьте в калькуляторе и найдите случай, когда дешевле выходит API.

Калькулятор: подписка или токены

Сколько стоил бы ваш чат, если платить по API? Помните урок 5: модель учитывает всё окно. По API вся история с каждым сообщением снова оплачивается как входные токены — поэтому их много больше, чем вы набрали.

Что видит провайдер

Облачная модель видит всё, что лежит в окне: вопрос, файлы, историю. Что с этим текстом происходит дальше, решают условия сервиса4.

Читают ли ваш текст люди? На серверах он хранится зашифрованным. У Anthropic сотрудники по умолчанию открыть переписку не могут. Исключений два: вы сами отправили отзыв о разговоре — или автоматическая проверка пометила его как нарушение правил; тогда его смотрит узкая группа проверяющих. У других провайдеров правила свои — читайте условия своего сервиса.

Неопубликованные данные

Результаты лаборатории до публикации — не для личного чата. Варианты: договор организации с провайдером или модель на своём компьютере (урок 10).

Биотехнология

Открытые статьи о ферментах можно отдавать любому облаку: они и так публичные. Неопубликованные кинетические данные своей лаборатории — другое дело. Три честных варианта: обезличить и отправить в чат; работать через API или тариф для организаций, где данные не идут на обучение; разбирать локально (урок 10).

Свои проекты

Бот «Жемчужины» на ftm разбирает заметки облачной моделью Claude Haiku — через API, со своим ключом. Ключ лежит отдельно от программы, в закрытом файле настроек на самом ftm: программу можно показать кому угодно, а ключ — никому. Расход виден в личном кабинете провайдера, там же стоит месячный лимит.

Главное
  • Облачная модель лежит на серверах провайдера; приложение и сайт — только окно к ней.
  • API — окошко модели для программ; ключ API — их пароль и ваш кошелёк.
  • Подписка — фиксированная плата и лимиты; API — оплата за входные и выходные токены, выходные дороже в 5 раз.
  • Облако видит ваш текст: что с ним дальше, решают условия тарифа. Полная приватность — только модель на своём компьютере.
Задание на 10 минут

Откройте настройки чата, которым пользуетесь, найдите и запишите три вещи.

  1. Запишите свой тариф.
  2. Найдите, где смотреть, сколько лимита осталось. В Claude: Настройки → Использование.
  3. Проверьте, включено ли использование переписки для обучения.
    • Claude: Настройки → Конфиденциальность → «Помогать улучшать Claude».
    • ChatGPT: Настройки → Управление данными → «Улучшить модель для всех».
  4. Решите, оставить ли настройку как есть, и запишите решение.
Сквозной проект · шаг 7

Что получится: в журнале проекта — запись типа решение из двух пунктов: на чём вы работаете и какие данные проекта можно отдавать провайдеру.

  1. Запишите тариф: каким продуктом и на каком тарифе вы работаете сейчас; включено ли обучение на вашей переписке (из задания выше).
  2. Запишите решение о данных: что из проекта можно отдавать провайдеру. Открытые статьи о ПЭТ-гидролазах — можно: они и так публичные. Свои неопубликованные измерения — нельзя либо только после обезличивания; запишите, как решили вы.

Где будет работать модель на каждом этапе — в облаке или на своём компьютере, — пока не решаем: это шаг 10, когда посчитаем память, скорость и деньги.
