Карта продуктов: чат, агент для документов, агент для кода

Одна и та же модель в разной обвязке становится разными продуктами. Где каждый работает, откуда у него инструменты и что вы получаете в конце.

Одна модель — разные обвязки

Claude, ChatGPT, Gemini — и в каждом по нескольку продуктов, названия которых меняются раз в полгода. Запоминать их бесполезно. Полезно уметь задать любому продукту четыре вопроса — тогда новое название вас не собьёт.

В уроке 11 мы разобрали: агент — это модель, инструменты и цикл. Модель в нём та же, что в чате. Меняется обвязка — программа вокруг модели. Она решает четыре вещи:

  • где идёт работа: на серверах провайдера или на вашем компьютере;
  • к чему есть доступ: только к переписке или ещё к папкам, почте, командам;
  • какие инструменты выданы: поиск, создание файлов, запуск программ;
  • чем заканчивается работа: ответом в чате, готовым файлом, изменёнными файлами проекта.
Образ

Один и тот же двигатель ставят в легковую машину, в фургон и в трактор. Двигатель тот же, а возят разное и по разным дорогам. Выбирая продукт, вы выбираете кузов, а не мотор1.

Поэтому одна и та же задача в чате и в агенте выходит разной по качеству: у агента есть инструменты, он может сделать десятки кругов и проверить себя, и ему дают больше времени «подумать». Модель при этом одна.

Три типа продуктов

Сверху вниз растут доступ и самостоятельность. Чат только отвечает. Агент для документов ходит по папкам и сайтам и собирает результат в файл. Часто он работает в песочнице — отдельном временном компьютере у провайдера, где может запускать программы, не трогая ваш. Агент для кода запускает команды прямо на том компьютере, где его открыли, — он может и починить, и сломать2. Поэтому у него строже разрешения: что он делает сам, а о чём спрашивает. Первые настройки — в уроке 13, подробно — в уроке 18.

Внутри у агента для документов и агента для кода один и тот же цикл из урока 11. Разные продукты из них сделали потому, что им нужен разный доступ по умолчанию и разный интерфейс: одному — папки и документы, другому — команды и файлы программ.

Где физически работает агент для кода

На том компьютере, где его запустили. Запустили на ноутбуке — работает в вашей папке на ноутбуке. Сергей, один из учащихся, запускает его на своём домашнем компьютере ftm (урок 7) и заходит туда удалённо — и агент меняет файлы на ftm. Модель при этом в любом случае на серверах провайдера.

Откуда у агента инструменты

Агенту из урока 11 был нужен поиск в UniProt. Откуда он берётся? Инструменты бывают двух видов.

  • Встроенные. Их даёт сам продукт: поиск в интернете, чтение и создание файлов, запуск программ. У агента для кода есть ещё чтение и правка файлов в папке проекта и команды компьютеру.
  • Подключённые сервисы (коннекторы). Вы сами разрешаете агенту ходить во внешний сервис — почту, диск, базу статей. Технически это чаще всего стандарт MCP: единые правила, по которым программа-«переходник» показывает агенту инструменты внешнего сервиса. Переходник пишут один раз, и он подходит к Claude, ChatGPT и другим обвязкам — как прибор к стандартной розетке3.

Пример для нашего проекта: в Claude есть коннектор PubMed — поиск статей, аннотации, перевод номеров PubMed в DOI. Включается в настройках, раздел «Коннекторы», бесплатно4. Официального коннектора к UniProt в общем каталоге Claude на ноябрь 2026 нет, но это не беда: у UniProt есть открытый API (урок 7), и агент для кода обращается к нему сам, как к адресу в интернете. Как это выглядит на деле — урок 14.

Не спрашивайте модель

Какие инструменты есть у агента, смотрите в списке подключённых сервисов и разрешений, а не спрашивайте у самой модели: о себе она тоже может выдумать (урок 6).

У Anthropic с сентября 2026 чат и агент для документов объединены: переключателя режимов нет, на простой вопрос Claude отвечает сразу, а большую работу берёт как задачу — с планом, шагами и файлами в конце.

Выбирайте по тому, что должно получиться в конце.

  • Нужен ответ, объяснение, черновик абзаца — чат. Быстро и дёшево.
  • Нужен файл из многих источников: сводка, таблица, презентация — агент для документов.
  • Нужно изменить файлы проекта или запустить программу — агент для кода.
Что брать для проекта

Уроки 11–12 — чат с поиском. С урока 13 — агент для кода Claude Code в папке проекта. Терминал не обязателен: Claude Code открывается вкладкой в приложении Claude для компьютера. Проведём по шагам.

Примеры

Биотехнология

Объяснить разницу между оптимумом температуры и термостабильностью — чат. Прочитать 15 статей о кутиназах и свести в таблицу с источниками — агент для документов. Написать программу, которая каждую ночь забирает новые записи из UniProt в таблицу проекта, — агент для кода.

Свои проекты

Спросить, чем польская фундация отличается от объединения (stowarzyszenie), — чат. Собрать досье по двадцати организациям в один документ — агент для документов. Добавить новую страницу на сайт этого курса и проверить, как она выглядит на телефоне, — агент для кода: меняются файлы сайта.

Главное
  • Модель одна, продукты разные: их различает обвязка — где работает, к чему доступ, чем заканчивается.
  • Три типа: чат (ответ), агент для документов (файл), агент для кода (изменения в папке проекта).
  • Инструменты бывают встроенные и подключённые; что есть на деле — смотрите в списке, а не спрашивайте модель.
  • Чем больше доступа, тем больше пользы и выше цена ошибки. Для проекта с урока 13 — агент для кода.
Задание на 10 минут

Откройте Claude (или ChatGPT) и дайте задачу посложнее вопроса: «Найди три обзорные статьи 2024–2026 годов о ферментах, разлагающих ПЭТ, и сделай таблицу: авторы, год, журнал, главный вывод». Найдите, где видно, что он работает над задачей: план, шаги, открытые страницы, файл в конце.

Затем откройте настройки, раздел коннекторов, и посмотрите, какие сервисы можно подключить. Запишите: что из этого есть в вашем тарифе и что пригодится проекту.

Сквозной проект · шаг 12

Вернитесь к записи шага 10, где у каждого этапа проекта (проектирование → сбор → извлечение → проверка → очистка → анализ → публикация и отчёт) уже стоит «облако» или «локально». Добавьте к каждому этапу второй столбец в той же таблице: чат, агент для документов или агент для кода — и одной фразой объясните выбор. Подсказка: всё, что меняет файлы данных проекта, — агент для кода.
