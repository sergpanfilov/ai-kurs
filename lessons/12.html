Карта продуктов: чат, агент для документов, агент для кода

Одна и та же модель в разной обвязке становится разными продуктами. Где каждый работает, откуда у него инструменты и что вы получаете в конце.

Одна модель — разные обвязки

Claude, ChatGPT, Gemini — и в каждом по нескольку продуктов, названия которых меняются раз в полгода. Запоминать их бесполезно. Полезно уметь задать любому продукту четыре вопроса — тогда новое название вас не собьёт.

В уроке 11 мы разобрали: агент — это модель, инструменты и цикл. Модель в нём та же, что в чате. Меняется обвязка — программа вокруг модели. Она решает четыре вещи:

  • где идёт работа: на серверах провайдера или на вашем компьютере;
  • к чему есть доступ: только к переписке или ещё к папкам, почте, командам;
  • какие инструменты выданы: поиск, создание файлов, запуск программ;
  • чем заканчивается работа: ответом в чате, готовым файлом, изменёнными файлами проекта.
Образ

Один и тот же двигатель ставят в легковую машину, в фургон и в трактор. Двигатель тот же, а возят разное и по разным дорогам. Выбирая продукт, вы выбираете кузов, а не мотор1.

Поэтому одна и та же задача в чате и в агенте выходит разной по качеству: агент может сделать десятки кругов и проверить себя.

Три типа продуктов

Сверху вниз растут доступ и самостоятельность. Агент для документов часто работает в песочнице — отдельном временном компьютере у провайдера, где может запускать программы, не трогая ваш. Агент для кода запускает команды прямо на том компьютере, где его открыли, — он может и починить, и сломать2. Поэтому у него строже разрешения: что он делает сам, а о чём спрашивает. Первые настройки — в уроке 14, подробно — в уроке 20.

Где физически работает агент для кода

Запустили на ноутбуке — работает в вашей папке на ноутбуке. Сергей запускает его на домашнем компьютере ftm (урок 7) и заходит туда удалённо — агент меняет файлы на ftm. Модель при этом всё равно на серверах провайдера.

Откуда у агента инструменты

Агенту из урока 11 был нужен поиск в UniProt. Откуда он берётся? Инструменты бывают двух видов.

  • Встроенные. Их даёт сам продукт: поиск в интернете, чтение и создание файлов, запуск программ. У агента для кода есть ещё чтение и правка файлов в папке проекта и команды компьютеру.
  • Подключённые сервисы (коннекторы). Вы сами разрешаете агенту ходить во внешний сервис — почту, диск, базу статей. Технически это чаще всего стандарт MCP: единые правила, по которым программа-«переходник» показывает агенту инструменты внешнего сервиса. Переходник пишут один раз, и он подходит к Claude, ChatGPT и другим обвязкам — как прибор к стандартной розетке3.

Пример для нашего проекта: в Claude есть коннектор PubMed — поиск статей, аннотации, перевод номеров PubMed в DOI (постоянный номер статьи; справка — урок 1). Включается в настройках, раздел «Коннекторы», бесплатно4.

Не спрашивайте модель

Какие инструменты есть у агента, смотрите в списке подключённых сервисов и разрешений, а не спрашивайте у самой модели: о себе она тоже может выдумать (урок 6).

Как агент на самом деле ходит в UniProt

В уроке 11 инструмент назывался условно: uniprot_search. Такого инструмента у Claude нет, и коннектора UniProt в общем каталоге на ноябрь 2026 тоже нет. На деле у агента для кода есть два общих инструмента — «открыть адрес» и «запустить команду». Ими он и обращается к открытому API UniProt (урок 7). Вот настоящий обмен, сокращённый:

агент просит: открыть адрес
rest.uniprot.org/uniprotkb/search?query=accession:G9BY57&fields=accession,protein_name,temp_dependence&format=tsv

ответ сайта: запись в машинном виде
G9BY57  Leaf-branch compost cutinase (LC-cutinase) (LCC) …  Temperature dependence: Optimum temperature is 50 degrees Celsius with pNP-butanoate as substrate (PubMed:22194294, PubMed:24593046). Optimum temperature using PET as substrate is superior to 70 degrees Celsius (PubMed:22194294). …

агент выписал
«Optimum temperature using PET as substrate is superior to 70 degrees Celsius»

Запрос и ответ настоящие, получены 11.11.2026; ответ сокращён. Адрес читается так: до первой косой черты — имя сайта, после знака вопроса — что именно нужно: запись G9BY57, три поля, вид «таблица текстом».

Ключ для UniProt не нужен. У многих научных баз API открыт: ни ключа, ни оплаты. Ключ нужен там, где считают деньги или доступ (урок 7).

А чат с поиском так может? Он открывает страницы сайта, как человек, — целиком, с оформлением. К API обращается агент для кода. Для пробы на два-три фермента годится и чат, для сбора — только агент для кода (урок 15).

У Anthropic с сентября 2026 чат и агент для документов объединены: переключателя нет, на простой вопрос Claude отвечает сразу, а большую работу берёт как задачу — с планом, шагами и файлами в конце.

Выбирайте по тому, что должно получиться в конце.

  • Нужен ответ, объяснение, черновик абзаца — чат. Быстро и дёшево.
  • Нужен файл из многих источников: сводка, таблица, презентация — агент для документов.
  • Нужно изменить файлы проекта или запустить программу — агент для кода. Он ещё умеет считать, проверять кодом и ходить к API — этим он и отличается от агента для документов в той же папке.
Что брать для проекта

Уроки 11–13 — бесплатный чат с поиском. С урока 14 — агент для кода Claude Code в папке проекта. Для него нужен платный план: Claude Pro, 20 $ в месяц (актуально на ноябрь 2026); на курс хватит одного-двух месяцев.

Примеры и проба

Биотехнология

Спросить, почему у одного фермента в разных статьях разный оптимум, — чат. Собрать по 15 статьям о кутиназах обзор на две страницы со ссылками — агент для документов. Пересчитать в таблице проекта все активности в одни единицы и проверить, что ничего не потерялось, — агент для кода.

Свои проекты

Спросить, чем польская фундация отличается от объединения (stowarzyszenie), — чат. Подготовить письмо в двадцать организаций по одному образцу — агент для документов. Исправить опечатку на всех страницах сайта этого курса разом — агент для кода: меняются файлы сайта.

Попробуйте сами

Восемь задач. Для каждой ответьте на два вопроса: что получится в конце (ответ, файл или изменённая папка) и чем делать. Три задачи — на границе: в них подходят два продукта, но платите вы за них разным.

Задачи условные, разбор — по правилу «что получится в конце». В задачах на границе засчитываются оба продукта, а разбор говорит, чем вы платите за каждый.

Частые вопросы

Можно ли заставить Claude взять работу как задачу? Кнопки нет — скажите словами: «сделай это как задачу: составь план и сохрани результат файлом». На бесплатном тарифе задач нет: Claude ответит в чате.

Можно ли верить коннектору как самой базе? Коннектор — программа-посредник: её написала либо сама база, либо третья сторона. Доверяйте как посреднику: число всё равно сверяется с записью базы (урок 15).

Главное
  • Модель одна, продукты разные: их различает обвязка — где работает, к чему доступ, чем заканчивается.
  • Три типа: чат (ответ), агент для документов (файл), агент для кода (изменения в папке проекта).
  • Инструменты бывают встроенные и подключённые; что есть на деле — смотрите в списке, а не спрашивайте модель.
  • Чем больше доступа, тем больше пользы и выше цена ошибки. Для проекта с урока 14 — агент для кода.
Задание на 10 минут

Откройте Claude (или ChatGPT) и дайте задачу посложнее вопроса: «Найди три обзорные статьи 2024–2026 годов о ферментах, разлагающих ПЭТ, и сделай таблицу: авторы, год, журнал, главный вывод». Смотрите, где видно, что он работает: строка хода работы, открытые страницы. На бесплатном тарифе Claude ответит таблицей в чате; на платном может взять работу как задачу — с планом и файлом в конце (актуально на ноябрь 2026).

Затем откройте настройки, раздел «Коннекторы», и посмотрите, какие сервисы можно подключить (в Claude раздел есть и на бесплатном тарифе; в ChatGPT он может называться иначе — если не нашли, пропустите). Запишите: какие два-три коннектора пригодились бы проекту и есть ли среди них PubMed.

Сквозной проект · шаг 12

Время: ≈ 10 минут. Откройте в журнале лист «Карта этапов» из шага 10: в строках семь этапов (проектирование → сбор → извлечение → очистка → проверка → анализ → публикация и отчёт; что значит каждый — таблица в шаге 1), в первом столбце уже стоит «где модель». Добавьте второй столбец — «какой продукт»: чат, агент для документов или агент для кода — и одной фразой объясните выбор. Подсказка: всё, что меняет файлы данных проекта, — агент для кода.
