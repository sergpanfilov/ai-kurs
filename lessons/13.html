Рабочее место: папка проекта и агент

Где физически живёт ваш проект, как открыть агента для кода в своей папке, какие настройки включить в первый же день и куда записывать решения.

Проект живёт в файлах

Модель ничего не помнит между разговорами (урок 3), а окно конечно (урок 5). Всё, что агент «знает» о проекте в начале новой сессии, обвязка кладёт в окно из файлов. Поэтому у проекта должно быть постоянное место — папка, где лежат правила, журнал, таблицы и статьи. Её читаете и вы, и агент.

Рабочая среда курса

С этого урока — Claude Code в папке проекта, через приложение Claude для компьютера. Нужен платный план (Pro — $20 в месяц, актуально на ноябрь 2026). Без него есть запасной путь — он ниже, в разделе «Открыть агента», с честным списком того, что получится, а что нет.

Файл, папка, формат

Файл — именованный кусок данных на диске. Папка — место, где лежат файлы и другие папки. Что внутри файла, подсказывает окончание имени — формат:

  • .txt и .md — просто текст. Markdown (.md) — текст с простой разметкой: # в начале строки — заголовок, - — пункт списка1. Его одинаково легко читают человек и агент.
  • .csv — таблица текстом: одна строка — одна запись, значения через запятую. Открывается в Excel и Google Таблицах.
  • .json — данные вида «имя поля: значение» в фигурных скобках: {"name": "LCC", "t_opt": 72}. Так одна строка таблицы выглядит для программ.
  • .pdf — свёрстанный документ, например статья.

Путь — адрес файла: ~/Projects/pet-enzymes/journal.md читается как «в домашней папке (~) → папка Projects → папка проекта → файл журнала».

Папка проекта

Правила (CLAUDE.md) короткие и ложатся в окно каждый раз — как инструкция на стене лаборатории. Всё остальное агент открывает по делу. Так окно не забивается, а знание о проекте не теряется между сессиями2.

Открыть агента в своей папке

Через приложение (без терминала). Установите приложение Claude для компьютера и войдите. Слева вверху — вкладка Code. Под полем ввода выберите среду Local (ваш компьютер), затем Open folder… и папку проекта3.

Через терминал. Перейдите в папку проекта и наберите claude. Установка — одна команда со страницы документации.

Дальше — разговор, как в чате. Разница в том, что агент действует на вашем компьютере: перед правкой он показывает, что именно изменит, и ждёт кнопки «да» или «нет». Команды с косой чертой набирают прямо в поле ввода: / покажет их список.

Запасной путь без Claude Code

В приложении Claude для компьютера можно дать обычному Claude доступ к папке: он читает и создаёт в ней файлы, пока приложение открыто. Так получатся уроки 14–17: пилотный сбор, ТЗ, приёмка. Не получатся или будут неудобны уроки 18–26: подчинённые агенты, тонкие правила доступа, история изменений, база в Supabase.

Первые настройки безопасности

Сколько агент делает без спроса, задаёт режим разрешений. Он виден под полем ввода; в терминале переключается клавишами Shift+Tab4.

РежимБез спросаСпрашивает
Manual (вручную)только чтение файлов в папкекаждую правку и команду
Accept editsчтение и правка файлов в папкекоманды
Planчтение; пишет план, ничего не меняетодобрить план
Autoпочти всё; рискованное останавливает отдельная модель-проверяльщикредко (урок 22)
Правило курса

До урока 18 работайте в режиме Manual. В терминале на ноябрь 2026 агент по умолчанию стартует в Auto — переключите. И помните: читать файлы в своей папке агент может без спроса в любом режиме. Поэтому секреты закрывают отдельным запретом: команда /permissions → правило запрета Read(./.env). Это запрет для встроенного чтения файлов; полная защита секретов — урок 25.

Инструменты и журнал

Встроено: чтение и правка файлов в папке, поиск и чтение страниц в интернете, запуск команд. Подключается: коннекторы по стандарту MCP (урок 12). Что есть на самом деле, смотрите командами: /mcp — подключённые сервисы, /permissions — правила. Не спрашивайте об этом модель: о себе она тоже может выдумать (урок 6).

Журнал из шага 1 переезжает в файл journal.md. Одна запись — дата, тип (решение, проверка, ошибка, сделано), что, почему и что отвергли. Настоящая запись из журнала этого курса:

## 2026-11-10 · решение
Адрес курса — agent.belhome.cc.
Почему: ai.belhome.cc уже занят другим сайтом.
Отвергли: переносить тот сайт.

Через полгода такая запись отвечает на вопрос «почему так», которого не помнит ни агент, ни вы. Читать папку с .md как записную книжку удобно в бесплатной программе Obsidian — по желанию5.

Что увидит агент

Попробуйте сами

Что увидит агент? Отметьте, какие файлы лежат в папке, выберите режим — и посмотрите, что агент прочитает в начале сессии, что изменит без спроса и о чём спросит.

Объёмы в токенах условные, порядок величин. Поведение режимов — по документации Claude Code, актуально на ноябрь 2026. Упрощение: на деле в режиме Plan агент может выполнять и безопасные команды для чтения.

Примеры

Биотехнология

Папка pet-enzymes: в CLAUDE.md три правила — «температуру писать в °C», «у каждого числа — источник и дословная фраза», «ничего не исправлять молча». В articles/ — пять статей о LCC и IsPETase. Агент открывает их по одной, а итог пишет в data/.

Свои проекты

Этот курс — тоже папка на ftm: уроки лежат в site/lessons/, отчёты учебной команды — в docs/review/, а в CHANGELOG.md — журнал «что и когда менялось». Каждая новая сессия агента начинает с правил и паспорта проекта и продолжает с того места, где остановилась прошлая.

Сноски
  1. Вся разметка Markdown на одной странице с примерами «как написать → как выглядит». Хватит 10 минут, чтобы читать и писать журнал и правила: Markdown Guide: Basic Syntax (справочник, англ., 10 мин).
  2. Claude Code в начале каждой сессии загружает файлы CLAUDE.md (свой в папке проекта и общий для всех проектов) и короткие заметки, которые агент ведёт сам. Это подсказка, а не замок: запреты задаются разрешениями. Claude Code Docs: How Claude remembers your project (документация, англ., 15 мин).
  3. Пошаговая инструкция от установки до первой правки, с тем, что вы увидите на экране: Claude Code Docs: Get started with the desktop app (инструкция, англ., 10 мин). Claude Code входит в планы Pro, Max, Ultra, Team и Enterprise; приложение есть для macOS, Windows и Linux (бета). Проверено 10.11.2026.
  4. Таблица всех режимов и того, что в каждом проходит без спроса; там же — с какого режима агент стартует в терминале, в приложении и в редакторе кода: Claude Code Docs: Choose a permission mode (документация, англ., 15 мин). Если терминал никогда не открывали — у той же документации есть Terminal guide for new users.
  5. Заметки Obsidian — обычные файлы .md в вашей папке: их читает любой редактор и любой агент, и они не пропадут вместе с сервисом. Глава Obsidian Стеф Анго назвал это «файл важнее программы»: Steph Ango: File over app (эссе, англ., 3 мин). Программа бесплатна; платные только синхронизация и публикация (актуально на ноябрь 2026).

Главное
  • Память проекта — файлы в одной папке: правила, журнал, ТЗ, таблицы, статьи.
  • В начале сессии в окно попадают только инструкции обвязки, CLAUDE.md и задание; остальное агент открывает по делу.
  • Claude Code открывают вкладкой Code в приложении или командой claude в терминале; до урока 18 — режим Manual и запрет на чтение секретов.
  • Что умеет агент, проверяют командами /mcp и /permissions, а не вопросом к модели.
Задание на 10 минут

Создайте пустую папку и откройте в ней Claude Code (или запасной путь). Включите режим Manual. Попросите: «Создай файл hello.md: заголовок — название моего проекта и три пункта списка о том, что он будет делать». Посмотрите, как агент спрашивает разрешения, и ответьте «да».

Откройте файл в обычном блокноте. Запишите: что спросил агент перед созданием файла, как выглядят # и - в тексте и что показала команда /permissions.

Сквозной проект · шаг 13

Создайте папку проекта по схеме: CLAUDE.md, journal.md, data/, articles/, notes/. Перенесите журнал из шагов 1–12 в journal.md, туда же — пять вопросов к базе (шаг 6) и словарь терминов (шаг 2). Запрет на чтение .env поставьте сразу, даже если файла ещё нет. Первая запись в новом файле — решение: какую рабочую среду выбрали и почему.
