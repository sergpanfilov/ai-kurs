Карта продуктов: чат, агент для документов, агент для кода

Одна и та же модель в разной обвязке становится разными продуктами. Где каждый работает, к чему у него есть доступ и что вы получаете в конце.

Одна модель — разные обвязки

В уроке 9 мы разобрали: агент — это модель, инструменты и цикл. Модель в нём одна и та же. Меняется обвязка — программа вокруг модели. Она решает четыре вещи:

  • где идёт работа: в окне браузера, в облачной «песочнице», на вашем компьютере;
  • к чему есть доступ: только к переписке или ещё к папкам, почте, терминалу;
  • какие инструменты выданы: поиск, создание файлов, запуск команд;
  • чем заканчивается работа: ответом в чате, готовым файлом, изменённой программой.
Образ

Один и тот же двигатель ставят в легковую машину, в фургон и в трактор. Двигатель тот же, а возят разное и по разным дорогам. Выбирая продукт, вы выбираете кузов, а не мотор1.

Из этих четырёх ответов сложились три типа продуктов, и у крупных разработчиков они устроены похоже.

Три типа продуктов

Сверху вниз растут доступ и самостоятельность. Чат только отвечает. Агент для документов ходит по папкам и сайтам и собирает результат в файл. Агент для кода запускает команды прямо на компьютере — он может и починить, и сломать2.

Что есть сейчас

Актуально на ноябрь 2026. Названия и тарифы меняются за месяцы — перепроверяйте.

Anthropic. С 16 сентября 2026 обычный чат и агент Cowork слиты в «один Claude»3. Режим больше не выбирают: на простой вопрос Claude отвечает сразу, а большую работу оформляет как задачу. Задача идёт в фоне, её можно проверить с телефона, а итог — документ, таблица или презентация. По умолчанию Claude спрашивает разрешения перед действиями. Сначала это получили платные планы Pro, Max и Ultra; Team и Free — позже. Projects — папки, где лежат файлы и инструкции для группы связанных разговоров. Отдельно живёт Claude Code — агент для кода: терминал, редактор кода, вкладка Code в приложении, веб; доступен с плана Pro4. Именно им сделан этот курс на сервере ftm.

OpenAI. С 9 июля 2026 в ChatGPT три режима5: Chat — разговор; Work — многочасовые задачи с готовыми документами, таблицами и презентациями, с доступом к подключённым сервисам6; Codex — агент для программирования, отдельный раздел приложения.

Google устроен похоже: приложение Gemini для разговора, а для кода — среда Antigravity, которая в мае 2026 заменила Gemini CLI7.

Осторожно

Граница между чатом и агентом для документов размывается: у Anthropic их уже объединили. Полезнее помнить не названия, а три вопроса: где работает, к чему имеет доступ, что отдаёт в конце.

Как выбрать

Выбирайте по тому, что должно получиться в конце.

  • Нужен ответ, объяснение, черновик абзаца — чат. Быстро и дёшево.
  • Нужен файл из многих источников: сводка, таблица, презентация — агент для документов.
  • Нужно что-то изменить в папке проекта или на сервере: код, настройки, база — агент для кода8.
Попробуйте сами

Восемь задач. Для каждой выберите тип продукта — появится разбор.

Задачи условные, разбор — по правилу «что получится в конце». Бывают задачи на границе: тогда работают оба варианта.

Примеры

Биотехнология

Объяснить разницу между оптимумом температуры и термостабильностью — чат. Прочитать 15 статей о кутиназах и свести в таблицу с источниками — агент для документов. Написать программу, которая каждую ночь забирает новые записи из UniProt в базу, — агент для кода.

Свои проекты

Спросить, чем польская фундация отличается от объединения (stowarzyszenie), — чат. Собрать досье по двадцати организациям в один документ — агент для документов. Поднять на ftm новую службу и прописать её в SERVER.md — агент для кода: ему нужны терминал и файлы.

Сноски
  1. Ту же мысль — модель, приложение и обвязка — развивает Итан Моллик, профессор Уортонской школы: для большинства задач обвязка уже важнее разницы между моделями. В гиде — какие продукты у трёх крупных компаний, что брать новичку и почему с агентом работа похожа больше на поручение, чем на разговор: Ethan Mollick: A Guide to Which AI to Use in the Agentic Era (статья, англ., февраль 2026, 20 мин). Названия продуктов в нём уже частично устарели — смотрите на логику выбора.
  2. Андрей Карпаты предлагает думать о «ползунке самостоятельности»: от подсказки по одному слову до агента, который сам меняет весь проект, — и держать ползунок там, где человек ещё успевает проверять результат. Andrej Karpathy: Software Is Changing (Again) (видео, англ., есть субтитры, 2025, 40 мин; про ползунок — во второй половине).
  3. Объявление Anthropic «Claude Cowork and chat are now one Claude», 16.09.2026, и статья справочного центра Claude. С 23.10.2026 объединение доступно и в плане Enterprise. Вместе с ним вышли бета-версии Claude Docs и Slides для платных планов.
  4. Страница продукта Claude Code (claude.com): терминал, расширения для VS Code и JetBrains, приложение для компьютера, веб, iOS и Android; нужен план Pro, Max, Ultra, Team или Enterprise либо оплата по API.
  5. Журнал изменений ChatGPT (learn.chatgpt.com, «What's new»): 6–10 июля 2026 — запуск ChatGPT Work и перенос Codex в приложение для компьютера рядом с Chat и Work. Доступность режимов зависит от тарифа.
  6. За подключёнными сервисами чаще всего стоит открытый стандарт MCP (Model Context Protocol): сервис пишут один раз, и подключить его можно к Claude, ChatGPT и другим обвязкам — как прибор к стандартной розетке. Первая страница официального сайта объясняет идею без кода: What is the Model Context Protocol (MCP)? (документация, англ., 5 мин).
  7. Google Developers Blog, 19.05.2026: «Transitioning Gemini CLI to Antigravity CLI».
  8. Насколько агент для кода реально ускоряет работу — вопрос открытый. В опыте METR (2025) опытные программисты с AI-помощниками работали на 19 % медленнее, хотя сами считали, что быстрее на 20 %. Разрыв между ощущением и замером — хороший повод проверять, а не верить: METR: Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity (исследование, англ., 15 мин). Что изменилось к 2026 году — в блоке «Куда движется область».

Подключённый сервисвнешняя программа, к которой агенту дали доступ: почта, диск, календарь (по-английски connector)
Терминалокно, где компьютеру дают команды текстом; рабочее место агента для кода
Главное
  • Модель одна, продукты разные: их различает обвязка — где работает, к чему доступ, чем заканчивается.
  • Три типа: чат (ответ), агент для документов (файл), агент для кода (изменения в проекте).
  • Чем больше доступа, тем больше пользы и тем выше цена ошибки.
  • Названия режимов меняются; выбирайте по тому, что должно получиться в конце.
Задание на 10 минут

Откройте приложение, которым пользуетесь (Claude или ChatGPT), и найдите, какие режимы в нём есть у вас: где переключатель, что написано в подсказках, какие сервисы можно подключить. Тарифы различаются, поэтому у вас может быть не всё.

Запишите таблицу из трёх строк: режим → где работает → к чему у него доступ → что он отдаёт в конце. Отметьте, чего в вашем тарифе нет.

Сквозной проект · шаг 10

Выпишите этапы проекта из таблицы ролей (проектирование, сбор, проверка, очистка, анализ, интерфейс) и для каждого выберите инструмент: чат, агент для документов или агент для кода. Одной фразой объясните выбор. Подсказка: всё, что меняет базу или сайт, — агент для кода.
